# InnoTech Portfolio

A modern, responsive portfolio website built with **HTML, CSS, and Bootstrap**, showcasing services, portfolio projects, and contact information.

---

## 🚀 Features

* **Responsive Design**: Optimized for desktop and mobile.
* **Bootstrap Integration**: Faster and consistent UI with Bootstrap components.
* **Animations**: Smooth fade and slide effects for an engaging experience.
* **Multi-Page Structure**: Includes separate sections for:

  * Home
  * Services
  * Portfolio
  * Contact

---
